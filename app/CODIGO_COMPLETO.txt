# Capim Dourado Shopping · Guia Acessível

Ecossistema de **totens de acessibilidade + Web App** para o Capim Dourado Shopping (Palmas/TO), criado pelo **Grupo 18 ENTEI** no **1º Hackrun UniCatólica**.

O visitante usa o totem ou lê o QR Code e o guia abre no próprio celular: rotas passo a passo nos dois pisos, guia por voz, alto contraste, comunicação por imagens e chamada de assistência (SOS).

## Problema

Pessoas surdas, cegas, com deficiência física ou intelectual e turistas estrangeiros enfrentam barreiras para se localizar e se comunicar dentro do shopping (38.800 m², 2 pavimentos). O projeto segue a **LBI (Lei nº 13.146/2015)**, a **ABNT NBR 9050** e as diretrizes **WCAG**.

## Funcionalidades

| Recurso | O que faz |
|---|---|
| **Tela de boas-vindas** | Logo oficial do shopping e "Toque em qualquer lugar para começar", com capim dourado animado. |
| **Mapa redondo (MVP de locais fixos)** | O prédio é oval, com corredor circular, jardim no átrio, passarelas nos 4 pontos cardeais e elevador panorâmico no centro. As zonas são setores fixos do anel nos dois pisos. |
| **Rotas por zona** | O visitante escolhe uma área (ex.: Praça de Alimentação). O mapa nomeia **só a zona de destino** e traça a rota seguindo a curva do corredor a partir do "Você está aqui". |
| **Bússola / HUD de orientação** | Faixa de bússola no estilo de jogo (N, NE, L, SE...) que gira com o rumo de cada passo, mais um selo com a direção: FRENTE, ESQUERDA, DIREITA, ELEVADOR, CHEGOU. A voz fala a mesma coisa ("À esquerda. ... sentido Norte"). |
| **Passo a passo** | Instruções com direção real (esquerda/direita), sentido cardeal, distância em metros, troca automática de piso e aviso de elevador. |
| **Mapa ilustrado** | Térreo e Piso 1 em estilo lúdico, com zoom e toque nas áreas. |
| **Guia por Voz** | Lê telas e rotas em voz alta (Text-to-Speech). |
| **Alto Contraste** | 1 toque: tema preto e amarelo em todo o app, incluindo o mapa. |
| **Modo Halloween** | 2 toques seguidos no botão Alto Contraste: preto e laranja (também acima de 7:1), com abóboras, morcegos, teias e a aranha que desce na tela de boas-vindas. |
| **Ajuda / SOS** | Chama um atendente até o totem; o chamado fica salvo no banco com status. |
| **Comunicação por Imagens (CAA)** | Pictogramas que falam a frase e mostram em tela cheia para o atendente. |
| **Voz** | Digite e o app fala, em português, inglês ou espanhol. |
| **Painel da Gestão** | Relatório para o shopping: destinos mais buscados (onde colocar publicidade e lojas), mapa de calor das buscas por zona e mapa de calor de uso dos recursos por horário (Design Thinking), com filtro totem/celular. Vem com dados de demonstração, que podem ser apagados. |
| **Modo Totem** | Emulação do totem físico com QR Code real, botões físicos e reinício após 90 s sem uso. |

## Arquitetura

- **Flutter** (código único): Web Mobile (QR Code), Totem e Android.
- **Banco de dados local Sembast** (NoSQL): IndexedDB no navegador e arquivo no Android.
  - `zonas`: áreas do mapa dos 2 pavimentos
  - `chamados_sos`: chamados de assistência e status
  - `eventos`: uso anônimo (rotas buscadas, recursos usados, origem totem/celular) para o Painel da Gestão
  - `preferencias`: alto contraste, Halloween e guia por voz
- **flutter_tts**: voz (Web Speech API no navegador).
- **qr_flutter**: QR Code do totem, que carrega a rota escolhida (`?destino=praca`).
- Acessibilidade com `Semantics` (rótulos, regiões ao vivo, estados de botões).

## Como rodar

Pré-requisito: [Flutter](https://docs.flutter.dev/get-started/install) 3.47 ou mais novo.

```bash
flutter pub get

# Celular (moldura de smartphone no navegador)
flutter run -d chrome

# Totem (compila, sobe servidor na rede local e abre o totem)
powershell -ExecutionPolicy Bypass -File rodar_totem.ps1

# Android (emulador ou aparelho)
flutter run -d android

# Testes
flutter test
```

No modo totem local, o celular precisa estar no **mesmo Wi-Fi** do PC para abrir o QR Code.

### Simulador em um único arquivo HTML

Gera um `.html` com o app inteiro embutido (código, motor gráfico, fontes e logo), que abre com dois cliques e funciona sem internet:

/// Texto-para-fala (TTS). No navegador usa a Web Speech API.
class Fala {
  final FlutterTts _tts = FlutterTts();

  Future<void> iniciar() async {
    try {
      await _tts.setLanguage('pt-BR');
      await _tts.setSpeechRate(kIsWeb ? 1.0 : 0.5);
      await _tts.setPitch(1.0);
    } catch (_) {}
  }

  Future<void> falar(String texto, {String idioma = 'pt-BR'}) async {
    try {
      await _tts.stop();
      await _tts.setLanguage(idioma);
      await _tts.speak(texto);
    } catch (_) {}
  }

  Future<void> parar() async {
    try {
      await _tts.stop();
    } catch (_) {}
  }
}

/// Estado global: banco, preferências de acessibilidade e voz.
class AppState extends ChangeNotifier {
  AppState(this.db) {
    // Guarda o horário real do último toque na tela (usado no duplo toque).
    GestureBinding.instance.pointerRouter.addGlobalRoute((e) {
      if (e is PointerDownEvent) _ultimoPointerDown = e.timeStamp;
    });
  }

  final ShoppingDatabase db;
  final Fala fala = Fala();

  bool altoContraste = false;

  /// Modo Halloween: alto contraste em laranja com abóboras, morcegos e teias.
  /// Ativado com 2 toques seguidos no botão Alto Contraste.
  bool halloween = false;
  bool guiaVoz = false;
  List<Zona> zonas = const [];
  Duration? _ultimoToqueContraste;
  Duration? _ultimoPointerDown;

  /// Local do totem onde o QR Code foi lido.
  final String localAtual = 'Totem da Entrada Principal · Térreo';

  Future<void> carregar() async {
    final prefs = await db.preferencias();
    altoContraste = (prefs['altoContraste'] as bool?) ?? false;
    halloween = altoContraste && ((prefs['halloween'] as bool?) ?? false);
    Cores.halloween = halloween;
    guiaVoz = (prefs['guiaVoz'] as bool?) ?? false;
    zonas = await db.zonas();
    await fala.iniciar();
  }

  /// Registra uso para o relatório de gestão (rotas mais buscadas e mapa de calor).
  Future<void> registrar(String tipo, String chave) async {
    try {
      await db.registrarEvento(tipo: tipo, chave: chave, origem: modoTotem ? 'totem' : 'celular');
    } catch (_) {}
  }

  /// Botão Alto Contraste:
  ///  - 1 toque: liga/desliga o alto contraste (preto e amarelo);
  ///  - 2 toques seguidos: ativa o modo Halloween (preto e laranja + decoração).
  ///
  /// O intervalo entre os toques é medido pelo horário do próprio toque
  /// (timestamp do evento), e não pela hora em que o código roda: a troca de
  /// tema pode travar a tela por um instante num aparelho lento, e o 2º toque
  /// ficaria "atrasado" na fila.
  Future<void> tocarContraste() async {
    final agora = _ultimoPointerDown ?? Duration(microseconds: DateTime.now().microsecondsSinceEpoch);
    _ultimoPointerDown = null;
    final duplo = _ultimoToqueContraste != null &&
        (agora - _ultimoToqueContraste!).abs() < const Duration(milliseconds: 700);
    _ultimoToqueContraste = duplo ? null : agora;

    if (duplo) {
      altoContraste = true;
      halloween = true;
    } else {
      altoContraste = !altoContraste;
      halloween = false;
    }
    Cores.halloween = halloween;
    notifyListeners();
    await db.salvarPreferencia('altoContraste', altoContraste);
    await db.salvarPreferencia('halloween', halloween);
    if (halloween) {
      registrar('recurso', 'halloween');
    } else if (altoContraste) {
      registrar('recurso', 'altoContraste');
    }
    await anunciar(halloween
        ? 'Modo Halloween ativado.'
        : (altoContraste ? 'Alto contraste ativado.' : 'Alto contraste desativado.'));
  }

  Future<void> alternarGuiaVoz() async {
    guiaVoz = !guiaVoz;
    notifyListeners();
    await db.salvarPreferencia('guiaVoz', guiaVoz);
    if (guiaVoz) registrar('recurso', 'guiaVoz');
    if (guiaVoz) {
      await fala.falar('Guia por voz ativado. Vou ler as telas e as rotas para você.');
    } else {
      await fala.falar('Guia por voz desativado.');
    }
  }

  /// Fala somente se o guia por voz estiver ligado.
  Future<void> anunciar(String texto) async {
    if (guiaVoz) await fala.falar(texto);
  }
}

import 'dart:math';

import 'package:sembast/sembast.dart';

import 'db_factory.dart';
import 'models.dart';
import 'seed.dart';

/// Banco de dados local (Sembast — NoSQL).
///
/// Coleções:
///  - `zonas`         → áreas do mapa (2 pavimentos)
///  - `chamados_sos`  → chamados de assistência enviados pelo usuário
///  - `eventos`       → métricas de uso (relatório de gestão e mapa de calor)
///  - `preferencias`  → alto contraste, guia por voz, versão dos dados
class ShoppingDatabase {
  ShoppingDatabase._(this._db);

  final Database _db;

  static final _zonas = stringMapStoreFactory.store('zonas');
  static final _sos = intMapStoreFactory.store('chamados_sos');
  static final _eventos = intMapStoreFactory.store('eventos');
  static final _prefs = StoreRef<String, Object?>('preferencias');

  /// Aumente quando mudar `seed.dart` para regravar o mapa.
  static const _versaoDados = 2;

  static Future<ShoppingDatabase> abrir() async {
    final db = ShoppingDatabase._(await abrirBanco('capim_dourado.db'));
    await db._popularSeNecessario();
    await db._criarDemonstracaoSeNecessario();
    return db;
  }

  Future<void> _popularSeNecessario() async {
    final versao = await _prefs.record('versao_dados').get(_db);
    if (versao == _versaoDados) return;
    await _db.transaction((txn) async {
      await _zonas.delete(txn);
      for (final z in zonasIniciais) {
        await _zonas.record(z.id).put(txn, z.toMap());
      }
      await _prefs.record('versao_dados').put(txn, _versaoDados);
    });
  }

  // ── Zonas ──
  Future<List<Zona>> zonas() async {
    final registros = await _zonas.find(_db);
    return registros.map((r) => Zona.fromMap(r.key, r.value)).toList();
  }

  // ── Preferências ──
  Future<Map<String, Object?>> preferencias() async {
    final registros = await _prefs.find(_db);
    return {for (final r in registros) r.key: r.value};
  }

  Future<void> salvarPreferencia(String chave, Object valor) =>
      _prefs.record(chave).put(_db, valor);

  // ── Chamados SOS ──
  Future<int> registrarChamado({required String tipo, required String local}) {
    return _sos.add(_db, {
      'tipo': tipo,
      'local': local,
      'status': 'Enviado',
      'criadoEm': DateTime.now().toIso8601String(),
    });
  }

  Future<void> atualizarStatus(int id, String status) =>
      _sos.record(id).update(_db, {'status': status});

  Future<List<ChamadoSos>> chamadosRecentes({int limite = 5}) async {
    final registros = await _sos.find(
      _db,
      finder: Finder(sortOrders: [SortOrder(Field.key, false)], limit: limite),
    );
    return registros.map((r) => ChamadoSos.fromMap(r.key, r.value)).toList();
  }

  // ── Métricas de uso ──
  Future<void> registrarEvento({required String tipo, required String chave, required String origem}) {
    return _eventos.add(_db, {
      'tipo': tipo,
      'chave': chave,
      'origem': origem,
      'criadoEm': DateTime.now().toIso8601String(),
      'demo': false,
    });
  }

  Future<List<Evento>> eventos() async {
    final registros = await _eventos.find(_db);
    return registros.map((r) => Evento.fromMap(r.value)).toList();
  }

  Future<void> apagarDemonstracao() async {
    await _eventos.delete(_db, finder: Finder(filter: Filter.equals('demo', true)));
    await _prefs.record('demo_apagada').put(_db, true);
  }

import 'dart:ui';

/// Geometria do shopping circular (formato oval/esférico do prédio).
///
/// Todas as elipses têm a mesma proporção; `k` é o "raio" normalizado:
///   k 0.20 → borda do elevador panorâmico (centro do átrio)
///   k 0.74 → borda interna do corredor circular
///   k 0.87 → linha central do corredor (por onde a rota passa)
///   k 1.00 → fachada das lojas (portas)
///   k 1.36 → fundo das lojas
///   k 1.42 → parede externa do prédio
/// Ângulos em graus no sentido da tela: 0 = leste (direita), 90 = sul (baixo,
/// entrada principal), 180 = oeste, 270 = norte (topo).
class Geo {
  static const centro = Offset(350, 490);
  static const ax = 220.0;
  static const by = 310.0;

  static const kElevador = 0.20;
  static const kAtrio = 0.74;
  static const kCorredor = 0.87;
  static const kFachada = 1.0;
  static const kFundo = 1.36;
  static const kParede = 1.42;

  /// Passarelas que ligam o elevador ao corredor (leste, sul, oeste, norte).
  static const passarelas = [0.0, 90.0, 180.0, 270.0];

  static Offset ponto(double k, double grau) {
    final t = grau * pi / 180;
    return centro + Offset(ax * k * cos(t), by * k * sin(t));
  }

  static double kDe(Offset p) {
    final d = p - centro;
    return sqrt(pow(d.dx / ax, 2) + pow(d.dy / by, 2));
  }

  static double grauDe(Offset p) {
    final d = p - centro;
    return norm(atan2(d.dy / by, d.dx / ax) * 180 / pi);
  }

  static double norm(double g) {
    final x = g % 360;
    return x < 0 ? x + 360 : x;
  }

  /// Menor diferença angular de `de` até `para`, em (-180, 180].
  static double delta(double de, double para) {
    var d = norm(para - de);
    if (d > 180) d -= 360;
    return d;
  }

  static bool noArco(double g, double a0, double a1) => norm(g - a0) <= (a1 - a0);

  /// Pontos ao longo do corredor circular, pelo caminho mais curto.
  static List<Offset> arco(double k, double de, double para) {
    final d = delta(de, para);
    final n = max(2, (d.abs() / 4).ceil());
    return [for (var i = 0; i <= n; i++) ponto(k, de + d * i / n)];
  }

  /// Contorno de um setor do anel (uma loja/zona).
  static Path setor(double k0, double k1, double a0, double a1) {
    final path = Path();
    final n = max(4, ((a1 - a0) / 2).ceil());
    for (var i = 0; i <= n; i++) {
      final p = ponto(k1, a0 + (a1 - a0) * i / n);
      i == 0 ? path.moveTo(p.dx, p.dy) : path.lineTo(p.dx, p.dy);
    }
    for (var i = n; i >= 0; i--) {
      final p = ponto(k0, a0 + (a1 - a0) * i / n);
      path.lineTo(p.dx, p.dy);
    }
    return path..close();
  }

  static Rect elipse(double k) =>
      Rect.fromCenter(center: centro, width: ax * k * 2, height: by * k * 2);

  /// Rumo de bússola (0 = Norte, 90 = Leste), do ponto `de` para `para`.
  static double rumo(Offset de, Offset para) {
    final v = para - de;
    return norm(atan2(v.dx, -v.dy) * 180 / pi);
  }

  static const _cardeais = ['Norte', 'Nordeste', 'Leste', 'Sudeste', 'Sul', 'Sudoeste', 'Oeste', 'Noroeste'];
  static const siglas = ['N', 'NE', 'L', 'SE', 'S', 'SO', 'O', 'NO'];

  static String cardinal(double rumo) => _cardeais[((norm(rumo) + 22.5) ~/ 45) % 8];
}

/// Uma zona (área) do mapa do shopping, armazenada no banco de dados.
///
/// Zonas do anel são setores entre os ângulos [ang0, ang1] (graus, ver [Geo]).
/// O elevador panorâmico fica no centro e usa o retângulo x/y/w/h.
class Zona {
  const Zona({
    required this.id,
    required this.nome,
    required this.categoria,
    required this.andar,
    required this.cor,
    required this.icone,
    this.ang0,
    this.ang1,
    this.x = 0,
    this.y = 0,
    this.w = 0,
    this.h = 0,
    this.destino = false,
    this.ordem = 99,
    this.descricao = '',
  });

  final String id;
  final String nome;
  final String categoria;

  /// 0 = Térreo, 1 = Piso 1.
  final int andar;
  final int cor;
  final String icone;
  final double? ang0, ang1;
  final double x, y, w, h;

  /// Aparece na lista de destinos de "Rotas".
  final bool destino;
  final int ordem;
  final String descricao;

  bool get ehSetor => ang0 != null && ang1 != null;
  double get angMeio => Geo.norm((ang0! + ang1!) / 2);
  Rect get rect => Rect.fromLTWH(x, y, w, h);
  String get nomeAndar => andar == 0 ? 'Térreo' : 'Piso $andar';

  /// Onde ficam o ícone e o nome da zona no mapa.
  Offset get centroRotulo =>
      ehSetor ? Geo.ponto((Geo.kFachada + Geo.kFundo) / 2, angMeio) : rect.center;

  bool contem(Offset p) {
    if (!ehSetor) return (p - rect.center).distance <= w / 2;
    final k = Geo.kDe(p);
    return k >= Geo.kFachada && k <= Geo.kFundo && Geo.noArco(Geo.grauDe(p), ang0!, ang1!);
  }

  Map<String, Object?> toMap() => {
        'nome': nome,
        'categoria': categoria,
        'andar': andar,
        'cor': cor,
        'icone': icone,
        'ang0': ang0,
        'ang1': ang1,
        'x': x,
        'y': y,
        'w': w,
        'h': h,
        'destino': destino,
        'ordem': ordem,
        'descricao': descricao,
      };

  factory Zona.fromMap(String id, Map<String, Object?> m) => Zona(
        id: id,
        nome: m['nome'] as String,

        w: (m['w'] as num?)?.toDouble() ?? 0,
        h: (m['h'] as num?)?.toDouble() ?? 0,
        destino: (m['destino'] as bool?) ?? false,
        ordem: (m['ordem'] as num?)?.toInt() ?? 99,
        descricao: (m['descricao'] as String?) ?? '',
      );
}

/// ~19.400 m² por pavimento → 1 unidade do mapa ≈ 0,18 m.
const double metrosPorUnidade = 0.18;

/// Totem da entrada principal (sul), de frente para o corredor circular.
final Offset pontoTotem = Geo.ponto(1.2, 90);

/// Direção relativa ao visitante, mostrada no indicador (HUD) e falada pela voz.
enum Direcao { inicio, frente, esquerda, direita, elevador, chegada }

class PassoRota {
  const PassoRota({
    required this.icone,
    required this.texto,
    required this.andar,
    required this.direcao,
    required this.rumo,
  });

  final IconData icone;
  final String texto;
  final int andar;
  final Direcao direcao;

  /// Rumo de bússola em graus (0 = Norte, 90 = Leste) ao cumprir o passo.
  final double rumo;

  String get sentido => Geo.cardinal(rumo);
}

class RotaCalculada {
  const RotaCalculada({
    required this.destino,
    required this.caminhos,
    required this.passos,
    required this.metros,
  });

  final Zona destino;

  /// Pontos do trajeto por andar.
  final Map<int, List<Offset>> caminhos;
  final List<PassoRota> passos;
  final double metros;

  bool get usaElevador => destino.andar != 0;
  int get minutos => max(1, (metros / 1.1 / 60).ceil());
  int get metrosArredondados => max(5, (metros / 5).round() * 5);
}

/// Porta da zona: na fachada, voltada para o corredor circular.
Offset portaDa(Zona z) => z.ehSetor ? Geo.ponto(Geo.kFachada, z.angMeio) : Geo.centro;

double _comprimento(List<Offset> pts) {
  var d = 0.0;
  for (var i = 1; i < pts.length; i++) {
    d += (pts[i] - pts[i - 1]).distance;
  }
  return d * metrosPorUnidade;
}

String _fmt(double metros) => '${max(5, (metros / 5).round() * 5)} metros';

RotaCalculada calcularRota(Zona destino) {
  final porta = portaDa(destino);
  final passos = <PassoRota>[];
  final caminhos = <int, List<Offset>>{};
  final anelSul = Geo.ponto(Geo.kCorredor, 90);

  passos.add(const PassoRota(
    icone: Icons.my_location,
    texto: 'Você está no totem da Entrada Principal, no Térreo, de frente para o corredor circular, sentido Norte.',
    andar: 0,
    direcao: Direcao.inicio,
    rumo: 0,
  ));

  if (destino.andar == 0) {
    final arco = Geo.arco(Geo.kCorredor, 90, destino.angMeio);
    caminhos[0] = [pontoTotem, ...arco, porta];
    final d = Geo.delta(90, destino.angMeio);
    final esquerda = d > 0; // sentido horário na tela = à esquerda de quem entra
    final rumoArco = Geo.rumo(arco[0], arco[1]);

    passos.add(PassoRota(
      icone: Icons.straight,
      texto: 'Siga em frente, sentido Norte, por cerca de ${_fmt(_comprimento([pontoTotem, anelSul]))} até o corredor circular.',
      andar: 0,
      direcao: Direcao.frente,
      rumo: 0,
    ));
    passos.add(PassoRota(
      icone: esquerda ? Icons.turn_left : Icons.turn_right,
      texto: 'Vire à ${esquerda ? 'esquerda' : 'direita'}, sentido ${Geo.cardinal(rumoArco)}, '
          'e acompanhe a curva do corredor por cerca de ${_fmt(_comprimento(arco))}.',
      andar: 0,
      direcao: esquerda ? Direcao.esquerda : Direcao.direita,
      rumo: rumoArco,
    ));
    final lado = esquerda ? 'esquerda' : 'direita';
    final rumoFinal = Geo.rumo(arco.last, porta);
    passos.add(PassoRota(
      icone: esquerda ? Icons.turn_left : Icons.turn_right,
      texto: '${destino.nome} fica à sua $lado, sentido ${Geo.cardinal(rumoFinal)}. Vire à $lado para entrar.',
      andar: 0,
      direcao: esquerda ? Direcao.esquerda : Direcao.direita,
      rumo: rumoFinal,
    ));
  } else {
    // Térreo: entrada → passarela sul → elevador panorâmico no centro.
    final elevadorSul = Geo.ponto(Geo.kElevador, 90);
    caminhos[0] = [pontoTotem, anelSul, elevadorSul];
    passos.add(PassoRota(
      icone: Icons.straight,
      texto: 'Siga em frente, sentido Norte, atravesse o corredor circular e continue pela passarela '
          'até o elevador panorâmico, no centro (cerca de ${_fmt(_comprimento(caminhos[0]!))}).',
      andar: 0,
      direcao: Direcao.frente,
      rumo: 0,
    ));
    passos.add(PassoRota(
      icone: Icons.elevator,
      texto: 'Pegue o elevador acessível e suba para o Piso ${destino.andar}.',
      andar: 0,
      direcao: Direcao.elevador,
      rumo: 0,
    ));

    // Piso de destino: sai pela passarela mais próxima do destino.
    final ponte = Geo.passarelas.reduce(
        (a, b) => Geo.delta(a, destino.angMeio).abs() <= Geo.delta(b, destino.angMeio).abs() ? a : b);
    final saida = Geo.ponto(Geo.kElevador, ponte);
    final anel = Geo.ponto(Geo.kCorredor, ponte);
    final d = Geo.delta(ponte, destino.angMeio);
    final arco = d.abs() < 6 ? [anel] : Geo.arco(Geo.kCorredor, ponte, destino.angMeio);
    caminhos[destino.andar] = [saida, ...arco, porta];
    final rumoPonte = Geo.rumo(saida, anel);

    passos.add(PassoRota(
      icone: Icons.straight,
      texto: 'Ao sair do elevador no Piso ${destino.andar}, siga pela passarela sentido ${Geo.cardinal(rumoPonte)} '
          'até o corredor circular (cerca de ${_fmt(_comprimento([saida, anel]))}).',
      andar: destino.andar,
      direcao: Direcao.frente,
      rumo: rumoPonte,
    ));

    if (arco.length == 1) {
      passos.add(PassoRota(
        icone: Icons.straight,
        texto: '${destino.nome} fica logo à sua frente, do outro lado do corredor.',
        andar: destino.andar,
        direcao: Direcao.frente,
        rumo: rumoPonte,
      ));
    } else {
      // Vindo de dentro para fora, o sentido horário fica à direita.
      final direita = d > 0;
      final rumoArco = Geo.rumo(arco[0], arco[1]);
      passos.add(PassoRota(
        icone: direita ? Icons.turn_right : Icons.turn_left,
        texto: 'Vire à ${direita ? 'direita' : 'esquerda'}, sentido ${Geo.cardinal(rumoArco)}, '
            'e acompanhe a curva do corredor por cerca de ${_fmt(_comprimento(arco))}.',
        andar: destino.andar,
        direcao: direita ? Direcao.direita : Direcao.esquerda,
        rumo: rumoArco,
      ));
      // No sentido horário, as lojas (lado de fora do anel) ficam à esquerda.
      final lado = d > 0 ? 'esquerda' : 'direita';
      final rumoFinal = Geo.rumo(arco.last, porta);
      passos.add(PassoRota(
        icone: lado == 'esquerda' ? Icons.turn_left : Icons.turn_right,
        texto: '${destino.nome} fica à sua $lado, sentido ${Geo.cardinal(rumoFinal)}.',
        andar: destino.andar,
        direcao: lado == 'esquerda' ? Direcao.esquerda : Direcao.direita,
        rumo: rumoFinal,
      ));
    }
  }

  passos.add(PassoRota(
    icone: Icons.flag_rounded,
    texto: 'Você chegou: ${destino.nome}!',
    andar: destino.andar,
    direcao: Direcao.chegada,
    rumo: passos.last.rumo,
  ));

  final metros = caminhos.values.fold(0.0, (s, c) => s + _comprimento(c));
  return RotaCalculada(destino: destino, caminhos: caminhos, passos: passos, metros: metros);
}

/// Mapa com rota passo a passo (quando há destino) ou modo exploração.
class MapaScreen extends StatefulWidget {
  const MapaScreen({super.key, this.destino});

  final Zona? destino;

  @override
  State<MapaScreen> createState() => _MapaScreenState();
}

class _MapaScreenState extends State<MapaScreen> {
  RotaCalculada? _rota;
  int _andar = 0;
  int _passo = 0;
  String? _aviso;

  /// Rumo exibido na bússola (acumulado para girar pelo caminho mais curto).
  double _rumo = 0;

  @override
  void initState() {
    super.initState();
    if (widget.destino != null) {
      _rota = calcularRota(widget.destino!);
      Future.microtask(() => rotaAtual.value = widget.destino!.id);
    }
    WidgetsBinding.instance.addPostFrameCallback((_) {
      final s = AppScope.read(context);
      if (_rota != null) {
        s.registrar('rota', _rota!.destino.id);
        s.anunciar('Rota até ${_rota!.destino.nome}, ${_rota!.destino.nomeAndar}. '
            'Cerca de ${_rota!.metrosArredondados} metros. ${_textoFalado(_rota!.passos.first)}');
      } else {
        s.registrar('recurso', 'mapa');
        s.anunciar('Mapa do shopping. O Norte fica para cima. Toque em uma área para ver o nome.');
      }
    });
  }

  @override
  void dispose() {
    final id = widget.destino?.id;
    if (id != null) {
      Future.microtask(() {
        if (rotaAtual.value == id) rotaAtual.value = null;
      });
    }
    super.dispose();
  }

  /// Texto para a voz, com a referência de direção (HUD) incluída.
  String _textoFalado(PassoRota p) => switch (p.direcao) {
        Direcao.esquerda => 'À esquerda. ${p.texto}',
        Direcao.direita => 'À direita. ${p.texto}',
        Direcao.frente => 'Em frente. ${p.texto}',
        _ => p.texto,
      };

  void _irParaPasso(int i) {
    final rota = _rota!;
    final passo = rota.passos[i];
    final trocouAndar = passo.andar != _andar;
    setState(() {
      _passo = i;
      _andar = passo.andar;
      _rumo += Geo.delta(_rumo, passo.rumo);
    });
    AppScope.read(context).anunciar(_textoFalado(passo));
    if (trocouAndar) {
      setState(() => _aviso = 'Agora você está no ${passo.andar == 0 ? 'Térreo' : 'Piso ${passo.andar}'}');
      Future<void>.delayed(const Duration(milliseconds: 2600), () {
        if (mounted) setState(() => _aviso = null);
      });
    }
  }

  void _tocouZona(Zona z) {
    final s = AppScope.read(context);
    final p = Paleta(s.altoContraste);
    s.anunciar(z.nome);
    showModalBottomSheet<void>(
      context: context,
      backgroundColor: p.cartao,
      shape: const RoundedRectangleBorder(borderRadius: BorderRadius.vertical(top: Radius.circular(24))),
      builder: (ctx) => Padding(
        padding: const EdgeInsets.fromLTRB(20, 20, 20, 32),
        child: Column(
          mainAxisSize: MainAxisSize.min,
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [

class _RelatorioScreenState extends State<RelatorioScreen> {
  List<Evento>? _eventos;
  String _origem = 'todos';
  int _andarCalor = 1;

  static const _recursos = {
    'rotas': 'Rotas',
    'mapa': 'Mapa',
    'guiaVoz': 'Guia por voz',
    'altoContraste': 'Alto contraste',
    'halloween': 'Modo Halloween',
    'sos': 'Ajuda / SOS',
    'caa': 'Imagens (CAA)',
    'voz': 'Voz',
  };
  static const _faixas = [10, 12, 14, 16, 18, 20];

  @override
  void initState() {
    super.initState();
    _carregar();
  }

  Future<void> _carregar() async {
    final e = await AppScope.read(context).db.eventos();
    if (mounted) setState(() => _eventos = e);
  }

  Future<void> _apagarDemo() async {
    await AppScope.read(context).db.apagarDemonstracao();
    await _carregar();
  }

  @override
  Widget build(BuildContext context) {
    final s = AppScope.of(context);
    final p = Paleta.of(context);
    final todos = _eventos;

    return Scaffold(
      backgroundColor: p.fundo,
      body: Column(
        children: [
          const Cabecalho(titulo: 'Painel da Gestão', subtitulo: 'Últimos 7 dias · totem e celular'),
          Expanded(
            child: todos == null
                ? const Center(child: CircularProgressIndicator())
                : _conteudo(context, s, p, todos),
          ),
        ],
      ),
    );
  }

  Widget _conteudo(BuildContext context, AppState s, Paleta p, List<Evento> todos) {
    final limite = DateTime.now().subtract(const Duration(days: 7));
    final eventos = todos
        .where((e) => e.criadoEm.isAfter(limite) && (_origem == 'todos' || e.origem == _origem))
        .toList();
    final temDemo = todos.any((e) => e.demo);
    final nomes = {for (final z in s.zonas) z.id: z.nome};

    final rotas = eventos.where((e) => e.tipo == 'rota').toList();
    final porDestino = <String, int>{};
    for (final e in rotas) {
      porDestino[e.chave] = (porDestino[e.chave] ?? 0) + 1;
    }
    final ranking = porDestino.entries.toList()..sort((a, b) => b.value.compareTo(a.value));

    final porHora = <int, int>{};
    for (final e in eventos) {
      final f = _faixa(e.criadoEm.hour);
      if (f != null) porHora[f] = (porHora[f] ?? 0) + 1;
    }
    final pico = porHora.entries.isEmpty ? null : porHora.entries.reduce((a, b) => a.value >= b.value ? a : b).key;

    final recursos = eventos.where((e) => e.tipo == 'recurso').toList();
    final grade = <String, Map<int, int>>{for (final r in _recursos.keys) r: {}};
    for (final e in recursos) {
      final f = _faixa(e.criadoEm.hour);
      if (f == null || !grade.containsKey(e.chave)) continue;
      grade[e.chave]![f] = (grade[e.chave]![f] ?? 0) + 1;
    }
    final totalRecurso = {for (final r in grade.entries) r.key: r.value.values.fold(0, (a, b) => a + b)};

    final base = MediaQuery.of(context).padding.bottom;
    return ListView(
      padding: EdgeInsets.fromLTRB(16, 14, 16, 24 + base),
      children: [
        // Filtro de origem (uma linha, acima de tudo)
        Wrap(spacing: 8, children: [
          for (final o in const {'todos': 'Todos', 'totem': 'Totem', 'celular': 'Celular'}.entries)
            ChoiceChip(
              label: Text(o.value),
              selected: _origem == o.key,
              onSelected: (_) => setState(() => _origem = o.key),
            ),
        ]),
        if (temDemo) ...[
          const SizedBox(height: 10),
          Container(
            padding: const EdgeInsets.fromLTRB(12, 8, 6, 8),
            decoration: BoxDecoration(
              color: p.ac ? Colors.black : const Color(0xFFFFF3E0),
              borderRadius: BorderRadius.circular(12),
              border: Border.all(color: p.ac ? Cores.amareloAC : const Color(0xFFFFB74D)),
            ),
            child: Row(children: [
              Icon(Icons.info_outline, color: p.ac ? Cores.amareloAC : const Color(0xFFE65100)),
              const SizedBox(width: 8),
              Expanded(
                child: Text('Inclui dados de demonstração para a apresentação.',
                    style: TextStyle(color: p.texto, fontSize: 13)),
              ),
              TextButton(onPressed: _apagarDemo, child: const Text('Apagar')),
            ]),
          ),
        ],
        const SizedBox(height: 14),
        // Números principais
        Row(children: [
          _Numero(rotulo: 'Buscas de rota', valor: '${rotas.length}'),
          const SizedBox(width: 8),
          _Numero(
              rotulo: 'Destino nº 1',
              valor: ranking.isEmpty ? '—' : (nomes[ranking.first.key] ?? ranking.first.key),
              pequeno: true),
          const SizedBox(width: 8),
          _Numero(rotulo: 'Horário de pico', valor: pico == null ? '—' : '${pico}h–${pico + 2}h', pequeno: true),
        ]),

        _Titulo('Destinos mais buscados'),
        if (ranking.isEmpty)
          Text('Ainda não há buscas de rota.', style: TextStyle(color: p.textoSuave))
        else
          for (final e in ranking)
            _Barra(
              rotulo: nomes[e.key] ?? e.key,
              valor: e.value,
              maximo: ranking.first.value,
              total: rotas.length,
            ),

        _Titulo('Mapa de calor das buscas'),
        Text('Quanto mais escura a zona, mais buscada. Use para posicionar publicidade e lojas no caminho.',
            style: TextStyle(color: p.textoSuave, fontSize: 13)),
        const SizedBox(height: 8),
        SegmentedButton<int>(
          showSelectedIcon: false,
          segments: const [
            ButtonSegment(value: 0, label: Text('Térreo')),
            ButtonSegment(value: 1, label: Text('Piso 1')),
          ],
          selected: {_andarCalor},
          onSelectionChanged: (v) => setState(() => _andarCalor = v.first),
        ),
        const SizedBox(height: 8),
        SizedBox(
          height: 360,
          child: MapaShopping(
            key: ValueKey('calor$_andarCalor'),
            zonas: s.zonas,
            andar: _andarCalor,
            altoContraste: s.altoContraste,
            halloween: s.halloween,
            calor: porDestino,
          ),
        ),
        _LegendaSequencial(escuro: p.ac),

        _Titulo('Uso dos recursos por horário'),
        Text('Mapa de calor de uso (Design Thinking): mostra o que é mais usado e quando.',
            style: TextStyle(color: p.textoSuave, fontSize: 13)),
        const SizedBox(height: 10),
        _GradeCalor(grade: grade, nomes: _recursos, faixas: _faixas, escuro: p.ac),
        _LegendaSequencial(escuro: p.ac),

        _Titulo('Recomendações'),
        ..._recomendacoes(ranking, rotas.length, nomes, totalRecurso, eventos, p),
      ],
    );
  }

  int? _faixa(int hora) {
    for (final f in _faixas) {
      if (hora >= f && hora < f + 2) return f;
    }
    return null;
  }

  List<Widget> _recomendacoes(List<MapEntry<String, int>> ranking, int totalRotas, Map<String, String> nomes,
      Map<String, int> totalRecurso, List<Evento> eventos, Paleta p) {
    final itens = <(IconData, String)>[];
    if (ranking.isNotEmpty && totalRotas > 0) {
      final top = ranking.first;
      final pct = (top.value * 100 / totalRotas).round();
      itens.add((
        Icons.campaign_outlined,
        '${nomes[top.key] ?? top.key} concentra $pct% das buscas. O caminho até lá é o melhor ponto para publicidade e para lojas de impulso.'
      ));
    }
    final usados = totalRecurso.entries.where((e) => e.key != 'rotas').toList()
      ..sort((a, b) => a.value.compareTo(b.value));
    if (usados.isNotEmpty) {
      final menos = usados.first;
      itens.add((
        Icons.psychology_alt_outlined,
        '${_recursos[menos.key]} é o recurso menos usado (${menos.value} usos). Próximo sprint: entrevistar usuários para entender a baixa adesão.'
      ));
    }
    final totem = eventos.where((e) => e.origem == 'totem').length;
    if (eventos.isNotEmpty) {
      final pct = (totem * 100 / eventos.length).round();
      itens.add((
        Icons.qr_code_2,
        '$pct% do uso vem do totem e ${100 - pct}% do celular (QR Code). Ajuda a decidir onde instalar novos totens.'
      ));
    }
    return [
      for (final i in itens)
        Padding(
          padding: const EdgeInsets.only(bottom: 10),
          child: Row(crossAxisAlignment: CrossAxisAlignment.start, children: [
            Icon(i.$1, color: p.destaque),
            const SizedBox(width: 10),
            Expanded(child: Text(i.$2, style: TextStyle(color: p.texto, fontSize: 15, height: 1.35))),
          ]),
        ),
    ];
  }
}

class _GradeCalor extends StatelessWidget {
  const _GradeCalor({required this.grade, required this.nomes, required this.faixas, required this.escuro});
  final Map<String, Map<int, int>> grade;
  final Map<String, String> nomes;
  final List<int> faixas;
  final bool escuro;

  @override
  Widget build(BuildContext context) {
    final p = Paleta.of(context);
    final maximo = max(1, grade.values.expand((m) => m.values).fold(0, max));
    return SingleChildScrollView(
      scrollDirection: Axis.horizontal,
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Row(children: [
            const SizedBox(width: 112),
            for (final f in faixas)
              SizedBox(
                width: 44,
                child: Text('${f}h',
                    textAlign: TextAlign.center,
                    style: TextStyle(color: p.textoSuave, fontSize: 11, fontWeight: FontWeight.w600)),
              ),
          ]),
          const SizedBox(height: 4),
          for (final r in grade.entries)
            Padding(
              padding: const EdgeInsets.only(bottom: 2),
              child: Row(children: [
                SizedBox(
                  width: 112,
                  child: Text(nomes[r.key] ?? r.key,
                      style: TextStyle(color: p.texto, fontSize: 12, fontWeight: FontWeight.w600)),
                ),
                for (final f in faixas)
                  Builder(builder: (_) {
                    final n = r.value[f] ?? 0;
                    final t = n / maximo;
                    final cor = corCalor(t, escuro: escuro);
                    final tintaClara = escuro ? t < 0.55 : t > 0.55;
                    return Tooltip(
                      message: '${nomes[r.key]} · ${f}h–${f + 2}h: $n usos',
                      child: Container(
                        width: 42,
                        height: 30,
                        margin: const EdgeInsets.only(right: 2),
                        alignment: Alignment.center,
                        decoration: BoxDecoration(color: cor, borderRadius: BorderRadius.circular(4)),

class _CapimPainter extends CustomPainter {
  _CapimPainter(this.t);

  final double t;

  @override
  void paint(Canvas canvas, Size size) {
    const n = 46;
    for (var i = 0; i < n; i++) {
      final semente = sin(i * 12.9898) * 43758.5453;
      final r = semente - semente.floorToDouble();
      final x = (i + 0.5) / n * size.width + (r - 0.5) * 10;
      final altura = 70 + r * 110;
      final balanco = sin(t * 2 * pi + i * 0.6) * (6 + r * 6);
      final topo = Offset(x + balanco + (r - 0.5) * 30, size.height - altura);
      final ctrl = Offset(x + balanco * 0.3, size.height - altura * 0.5);

      final cor = Color.lerp(const Color(0xFFC8961E), const Color(0xFFE9C46A), r)!;
      final haste = Path()
        ..moveTo(x, size.height)
        ..quadraticBezierTo(ctrl.dx, ctrl.dy, topo.dx, topo.dy);
      canvas.drawPath(
        haste,
        Paint()
          ..color = cor.withValues(alpha: 0.85)
          ..style = PaintingStyle.stroke
          ..strokeWidth = 2.2
          ..strokeCap = StrokeCap.round,
      );
      // "Flor" dourada na ponta, típica do capim dourado do Jalapão
      canvas.drawCircle(topo, 3.2 + r * 2.2, Paint()..color = const Color(0xFFDDA92A));
    }
  }

  @override
  bool shouldRepaint(_CapimPainter old) => old.t != t;
}

/// Detalhe de Halloween: uma aranha desce pelo fio até o centro,
/// balança por 1,5 s e sobe desaparecendo. Não bloqueia nada depois.
class AranhaOverlay extends StatefulWidget {
  const AranhaOverlay({super.key, required this.aoTerminar});

  final VoidCallback aoTerminar;

  @override
  State<AranhaOverlay> createState() => _AranhaOverlayState();
}

class _AranhaOverlayState extends State<AranhaOverlay> with SingleTickerProviderStateMixin {
  late final AnimationController _c = AnimationController(
    vsync: this,
    duration: const Duration(milliseconds: 3300),
  )
    ..addStatusListener((s) {
      if (s == AnimationStatus.completed) widget.aoTerminar();
    })
    ..forward();

  @override
  void dispose() {
    _c.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return IgnorePointer(
      child: ExcludeSemantics(
        child: AnimatedBuilder(
          animation: _c,
          builder: (_, _) => CustomPaint(
            size: Size.infinite,
            painter: _AranhaPainter(_c.value),
          ),
        ),
      ),
    );
  }
}

class _AranhaPainter extends CustomPainter {
  _AranhaPainter(this.t);

  final double t;

  static const _fimDescida = 1000 / 3300;
  static const _fimPausa = 2500 / 3300;

  @override
  void paint(Canvas canvas, Size size) {
    final alvo = size.height * 0.42;
    double y;
    double balanco;
    double opacidade = 1;
    double teia;
    double pernas = 0;

    if (t < _fimDescida) {
      final k = t / _fimDescida;
      y = -170 + (alvo + 170) * Curves.easeOutBack.transform(k);
      balanco = sin(k * pi) * 0.05;
      teia = k;
    } else if (t < _fimPausa) {
      final k = (t - _fimDescida) / (_fimPausa - _fimDescida);
      y = alvo + sin(k * pi * 3) * 6;
      balanco = sin(k * pi * 2) * 0.06;
      pernas = sin(k * pi * 8);
      teia = 1;
    } else {
      final k = Curves.easeIn.transform((t - _fimPausa) / (1 - _fimPausa));
      y = alvo - (alvo + 220) * k;
      balanco = 0;
      opacidade = 1 - k;
      teia = 1 - k;
    }

    // Teia no canto superior direito
    final teiaPaint = Paint()
      ..color = const Color(0xFF3A3A3A).withValues(alpha: 0.55 * teia)
      ..style = PaintingStyle.stroke
      ..strokeWidth = 1.3;
    _teia(canvas, Offset(size.width, 0), 130, pi / 2, pi, teiaPaint);
    _teia(canvas, Offset.zero, 80, 0, pi / 2, teiaPaint);

    final cor = const Color(0xFF111111).withValues(alpha: opacidade);

    canvas.save();
    canvas.translate(size.width / 2, 0);
    canvas.rotate(balanco);

    // Fio
    canvas.drawLine(
      Offset.zero,
      Offset(0, y - 58),
      Paint()
        ..color = const Color(0xFF222222).withValues(alpha: opacidade)
        ..strokeWidth = 2,
    );

    canvas.translate(0, y);
    canvas.scale(0.85);
    _aranha(canvas, cor, pernas);
    canvas.restore();
  }

  void _aranha(Canvas canvas, Color cor, double mexer) {
    final corpo = Paint()..color = cor;

    const pernas = [
      [Offset(12, 6), Offset(38, -34), Offset(46, -112)],
      [Offset(17, 12), Offset(78, 8), Offset(128, -28)],
      [Offset(17, 20), Offset(72, 40), Offset(108, 112)],
      [Offset(12, 26), Offset(42, 78), Offset(48, 150)],
    ];

    for (final lado in [-1.0, 1.0]) {
      for (var i = 0; i < pernas.length; i++) {
        final p = pernas[i];
        final ajuste = Offset(0, mexer * (i.isEven ? 4 : -4));
        final a = Offset(p[0].dx * lado, p[0].dy);
        final b = Offset(p[1].dx * lado, p[1].dy) + ajuste * 0.5;
        final c = Offset(p[2].dx * lado, p[2].dy) + ajuste;
        canvas.drawLine(a, b, Paint()
          ..color = cor
          ..strokeWidth = 6.5
          ..strokeCap = StrokeCap.round);
        canvas.drawLine(b, c, Paint()
          ..color = cor
          ..strokeWidth = 3.8
          ..strokeCap = StrokeCap.round);
      }
    }

    // Abdômen, cefalotórax e cabeça
    canvas.drawOval(Rect.fromCenter(center: const Offset(0, -28), width: 54, height: 64), corpo);
    canvas.drawOval(Rect.fromCenter(center: const Offset(0, 18), width: 38, height: 34), corpo);
    canvas.drawOval(Rect.fromCenter(center: const Offset(0, 38), width: 20, height: 13), corpo);

    // Brilho sutil e olhinhos
    canvas.drawOval(
      Rect.fromCenter(center: const Offset(-11, -42), width: 12, height: 18),
      Paint()..color = Colors.white.withValues(alpha: 0.12 * cor.a),
    );
    final olho = Paint()..color = Colors.white.withValues(alpha: 0.8 * cor.a);
    canvas.drawCircle(const Offset(-4, 39), 1.8, olho);
    canvas.drawCircle(const Offset(4, 39), 1.8, olho);
  }

  void _teia(Canvas canvas, Offset canto, double raio, double angIni, double angFim, Paint p) {
    const n = 6;
    final angs = List.generate(n, (i) => angIni + (angFim - angIni) * i / (n - 1));
    for (final a in angs) {
      canvas.drawLine(canto, canto + Offset(cos(a), sin(a)) * raio, p);
    }
    for (var r = raio * 0.25; r <= raio; r += raio * 0.22) {
      final path = Path();
      for (var i = 0; i < n; i++) {
        final pt = canto + Offset(cos(angs[i]), sin(angs[i])) * r;
        if (i == 0) {
          path.moveTo(pt.dx, pt.dy);
        } else {
          final am = (angs[i - 1] + angs[i]) / 2;
          final ctrl = canto + Offset(cos(am), sin(am)) * r * 0.82;
          path.quadraticBezierTo(ctrl.dx, ctrl.dy, pt.dx, pt.dy);
        }
      }
      canvas.drawPath(path, p);
    }
  }

  @override
  bool shouldRepaint(_AranhaPainter old) => old.t != t;
}

/// Desenha uma abóbora de Halloween centrada em [c], com altura [t].
void desenharAbobora(Canvas canvas, Offset c, double t, {bool rosto = true}) {
  final w = t * 1.25;
  final corpo = Paint()..color = const Color(0xFFFF7A00);
  final gomo = Paint()..color = const Color(0xFFE56500);
  final contorno = Paint()
    ..color = const Color(0xFF8A3A00)
    ..style = PaintingStyle.stroke
    ..strokeWidth = t * 0.04;

  // Cabinho
  canvas.drawRRect(
    RRect.fromRectAndRadius(
        Rect.fromCenter(center: c.translate(t * 0.04, -t * 0.5), width: t * 0.14, height: t * 0.26),
        Radius.circular(t * 0.05)),
    Paint()..color = const Color(0xFF3E7D2C),
  );
  // Gomos laterais e central
  for (final dx in [-0.32, 0.32]) {
    final r = Rect.fromCenter(center: c.translate(w * dx, 0), width: w * 0.55, height: t * 0.9);
    canvas.drawOval(r, gomo);
    canvas.drawOval(r, contorno);
  }
  final centro = Rect.fromCenter(center: c, width: w * 0.6, height: t * 0.96);
  canvas.drawOval(centro, corpo);
  canvas.drawOval(centro, contorno);

  if (!rosto) return;
  final rostoPaint = Paint()..color = const Color(0xFF1A0E00);
  final brilho = Paint()..color = const Color(0xFFFFD54F);
  // Olhos triangulares
  for (final dx in [-0.17, 0.17]) {
    final o = c.translate(w * dx, -t * 0.1);
    final p = Path()
      ..moveTo(o.dx - t * 0.09, o.dy + t * 0.06)
      ..lineTo(o.dx + t * 0.09, o.dy + t * 0.06)
      ..lineTo(o.dx, o.dy - t * 0.09)
      ..close();
    canvas.drawPath(p, brilho);
    canvas.drawPath(p.shift(Offset(0, t * 0.015)), rostoPaint);
  }
  // Boca em zigue-zague
  final boca = Path()..moveTo(c.dx - w * 0.24, c.dy + t * 0.12);
  for (var i = 0; i <= 6; i++) {
    final x = c.dx - w * 0.24 + w * 0.48 * i / 6;
    boca.lineTo(x, c.dy + t * (i.isEven ? 0.12 : 0.2));
  }
  boca.quadraticBezierTo(c.dx, c.dy + t * 0.36, c.dx - w * 0.24, c.dy + t * 0.12);
  canvas.drawPath(boca, rostoPaint);
}

/// Morcego simples com asas batendo ([fase] 0..1).
void desenharMorcego(Canvas canvas, Offset c, double t, double fase, Color cor) {
  final asa = sin(fase * 2 * pi) * 0.35;
  final p = Paint()..color = cor;
  for (final lado in [-1.0, 1.0]) {
    final path = Path()
      ..moveTo(c.dx, c.dy)
      ..quadraticBezierTo(c.dx + lado * t * 0.5, c.dy - t * (0.5 + asa), c.dx + lado * t, c.dy - t * asa)
      ..quadraticBezierTo(c.dx + lado * t * 0.75, c.dy + t * 0.05, c.dx + lado * t * 0.55, c.dy + t * 0.18)
      ..quadraticBezierTo(c.dx + lado * t * 0.35, c.dy + t * 0.02, c.dx, c.dy + t * 0.12)
      ..close();
    canvas.drawPath(path, p);
  }
  canvas.drawOval(Rect.fromCenter(center: c.translate(0, t * 0.05), width: t * 0.26, height: t * 0.34), p);
}

          ),
          child: Row(children: [
            Icon(icone, color: ac ? Colors.black : Colors.white, size: 26),
            const SizedBox(width: 4),
            Text(rotulo,
                style: TextStyle(color: ac ? Colors.black : Colors.white, fontSize: 13, fontWeight: FontWeight.w900)),
          ]),
        ),
      ],
    );
  }
}

class _BussolaPainter extends CustomPainter {
  _BussolaPainter(this.rumo, this.tinta, this.destaque);

  final double rumo;
  final Color tinta, destaque;

  @override
  void paint(Canvas canvas, Size size) {
    const campo = 180.0; // graus visíveis na faixa
    final pxPorGrau = size.width / campo;
    final centro = size.width / 2;
    final r = Geo.norm(rumo);

    final traco = Paint()
      ..color = tinta.withValues(alpha: 0.45)
      ..strokeWidth = 1.5;
    for (var g = 0; g < 360; g += 15) {
      final dx = Geo.delta(r, g.toDouble()) * pxPorGrau;
      if (dx.abs() > size.width / 2 + 10) continue;
      final x = centro + dx;
      final ehCardeal = g % 45 == 0;
      if (ehCardeal) {
        final sigla = Geo.siglas[g ~/ 45];
        final tp = TextPainter(
          text: TextSpan(
            text: sigla,
            style: TextStyle(
              color: g == 0 ? destaque : tinta,
              fontSize: sigla.length == 1 ? 17 : 13,
              fontWeight: FontWeight.w900,
            ),
          ),
          textDirection: TextDirection.ltr,
        )..layout();
        tp.paint(canvas, Offset(x - tp.width / 2, size.height / 2 - tp.height / 2 - 4));
        canvas.drawLine(Offset(x, size.height - 9), Offset(x, size.height - 2), traco..strokeWidth = 2);
      } else {
        canvas.drawLine(Offset(x, size.height - 7), Offset(x, size.height - 2), traco..strokeWidth = 1.5);
      }
    }

    // Marcador central = para onde o visitante está indo
    final m = Path()
      ..moveTo(centro - 8, 0)
      ..lineTo(centro + 8, 0)
      ..lineTo(centro, 9)
      ..close();
    canvas.drawPath(m, Paint()..color = destaque);
    canvas.drawLine(Offset(centro, 9), Offset(centro, size.height),
        Paint()
          ..color = destaque.withValues(alpha: 0.5)
          ..strokeWidth = 2);
  }

  @override
  bool shouldRepaint(_BussolaPainter old) => old.rumo != rumo || old.tinta != tinta;
}

/// Mapa ilustrado de um pavimento do shopping circular, com rota animada.
/// Com [calor], pinta cada zona pela quantidade de buscas (mapa de calor).
class MapaShopping extends StatefulWidget {
  const MapaShopping({
    super.key,
    required this.zonas,
    required this.andar,
    required this.altoContraste,
    this.destino,
    this.caminho,
    this.onTapZona,
    this.calor,
    this.halloween = false,
  });

  final bool halloween;
  final List<Zona> zonas;
  final int andar;
  final bool altoContraste;
  final Zona? destino;
  final List<Offset>? caminho;
  final ValueChanged<Zona>? onTapZona;
  final Map<String, int>? calor;

  @override
  State<MapaShopping> createState() => _MapaShoppingState();
}

class _MapaShoppingState extends State<MapaShopping> with TickerProviderStateMixin {
  late final AnimationController _tracejado =
      AnimationController(vsync: this, duration: const Duration(milliseconds: 1400))..repeat();
  late final AnimationController _pulso =
      AnimationController(vsync: this, duration: const Duration(milliseconds: 1800))..repeat();
  late final AnimationController _caminhada =
      AnimationController(vsync: this, duration: const Duration(milliseconds: 5200))..repeat();
  final _transformacao = TransformationController();

  @override
  void didUpdateWidget(MapaShopping old) {
    super.didUpdateWidget(old);
    if (old.andar != widget.andar || old.caminho != widget.caminho) {
      _caminhada
        ..reset()
        ..repeat();
      _transformacao.value = Matrix4.identity();
    }
  }

  @override
  void dispose() {
    _tracejado.dispose();
    _pulso.dispose();
    _caminhada.dispose();
    _transformacao.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return LayoutBuilder(builder: (context, c) {
      final w = min(c.maxWidth, c.maxHeight * 0.7);
      final h = w / 0.7;
      final escala = w / 700;
      return InteractiveViewer(
        transformationController: _transformacao,
        minScale: 1,
        maxScale: 4,
        boundaryMargin: const EdgeInsets.all(60),
        child: SizedBox(
          width: c.maxWidth,
          height: c.maxHeight,
          child: Center(
            child: GestureDetector(
              onTapUp: widget.onTapZona == null
                  ? null
                  : (d) {
                      final pt = d.localPosition / escala;
                      for (final z in widget.zonas.where((z) => z.andar == widget.andar)) {
                        if (z.contem(pt)) {
                          widget.onTapZona!(z);
                          break;
                        }
                      }
                    },
              child: SizedBox(
                width: w,
                height: h,
                child: CustomPaint(
                  painter: _MapaPainter(
                    zonas: widget.zonas.where((z) => z.andar == widget.andar).toList(),
                    andar: widget.andar,
                    destino: widget.destino,
                    caminho: widget.caminho,
                    calor: widget.calor,
                    ac: widget.altoContraste,
                    halloween: widget.halloween,
                    tracejado: _tracejado,
                    pulso: _pulso,
                    caminhada: _caminhada,
                  ),
                ),
              ),
            ),
          ),
        ),
      );
    });
  }
}

/// Escala sequencial de uma só matiz (claro → escuro) para o mapa de calor.
Color corCalor(double t, {bool escuro = false}) {
  if (escuro) return Color.lerp(const Color(0xFF3A2410), const Color(0xFFFFB04A), t)!;
  return Color.lerp(const Color(0xFFFCE8C8), const Color(0xFFB34700), t)!;
}

class _MapaPainter extends CustomPainter {
  _MapaPainter({
    required this.zonas,
    required this.andar,
    required this.destino,
    required this.caminho,
    required this.calor,
    required this.ac,
    required this.halloween,
    required this.tracejado,
    required this.pulso,
    required this.caminhada,
  }) : super(repaint: Listenable.merge([tracejado, pulso, caminhada]));

  final List<Zona> zonas;
  final int andar;
  final Zona? destino;
  final List<Offset>? caminho;
  final Map<String, int>? calor;
  final bool ac;
  final bool halloween;
  final Animation<double> tracejado, pulso, caminhada;

  Color get _corRota => ac ? Cores.amareloAC : Cores.laranjaRota;
  static const _azul = Color(0xFF1E88E5);
  bool get _temRota => caminho != null && caminho!.length > 1;

  @override
  void paint(Canvas canvas, Size size) {
    canvas.save();
    canvas.scale(size.width / 700, size.height / 1000);
    _fundo(canvas);
    _predio(canvas);
    for (final z in zonas) {
      _zona(canvas, z);
    }
    if (_temRota) _rota(canvas);
    if (andar == 0 && calor == null) {
      _voceEstaAqui(canvas);
    } else if (_temRota) {
      _saidaElevador(canvas, caminho!.first);
    }
    if (destino != null && destino!.andar == andar) {
      _pino(canvas, portaDa(destino!));
      _rotuloDestino(canvas, destino!);
    }
    _rosaDosVentos(canvas, const Offset(68, 918));
    canvas.restore();
  }

  // ── Gramado, árvores (ou abóboras no modo Halloween) e praça de entrada ──
  void _fundo(Canvas c) {
    c.drawRect(const Rect.fromLTWH(0, 0, 700, 1000),
        Paint()..color = halloween ? const Color(0xFF0B0712) : (ac ? Colors.black : const Color(0xFFCFE6B4)));
    final copa = Paint()..color = const Color(0xFF7CB860);
    final copaEscura = Paint()..color = const Color(0xFF5E9A48);
    for (var g = 0.0; g < 360; g += 22.5) {
      if (g > 60 && g < 120) continue; // praça de entrada
      final p = Geo.ponto(1.56, g);
      if (p.dx < 20 || p.dx > 680 || p.dy < 18 || p.dy > 985) continue;
      if ((p - const Offset(68, 918)).distance < 70) continue; // rosa dos ventos
      if (halloween) {
        desenharAbobora(c, p, 26, rosto: g % 45 == 0);
      } else if (!ac) {
        c.drawCircle(p.translate(0, 4), 14, copaEscura);
        c.drawCircle(p, 13, copa);
      }
    }
    if (andar == 0) {
      final praca = Path()
        ..addOval(Rect.fromCenter(center: Geo.ponto(1.5, 90), width: 260, height: 90));
      c.drawPath(praca,
          Paint()..color = halloween ? const Color(0xFF1C1424) : (ac ? const Color(0xFF1A1A1A) : const Color(0xFFEADBB8)));
      if (halloween) {
        desenharAbobora(c, Geo.ponto(1.5, 90).translate(-150, 6), 34);
        desenharAbobora(c, Geo.ponto(1.5, 90).translate(150, 6), 34);
      }
    }
  }

  void _predio(Canvas c) {
    final parede = Geo.elipse(Geo.kParede);
    if (!ac) {
      c.drawOval(parede.shift(const Offset(0, 10)),
          Paint()
            ..color = Colors.black.withValues(alpha: 0.18)
            ..maskFilter = const MaskFilter.blur(BlurStyle.normal, 14));
    }
    c.drawOval(parede, Paint()..color = ac ? const Color(0xFF141414) : const Color(0xFFFFF4DA));
    c.drawOval(
        parede,
        Paint()
          ..style = PaintingStyle.stroke
          ..strokeWidth = 5
          ..color = ac ? Colors.white : const Color(0xFFB88A3A));

    // Hall de entrada (sul) no Térreo
    if (andar == 0) {
      c.drawPath(Geo.setor(Geo.kFachada, Geo.kParede, 75, 105),
          Paint()..color = ac ? const Color(0xFF2B2B2B) : const Color(0xFFF1E1BA));
      final porta = Geo.ponto(Geo.kParede, 90);
      c.drawRRect(
          RRect.fromRectAndRadius(Rect.fromCenter(center: porta, width: 90, height: 18), const Radius.circular(8)),
          Paint()..color = ac ? Cores.amareloAC : Cores.dourado);
    }

    // Corredor circular
    final corPiso = ac ? const Color(0xFF2B2B2B) : const Color(0xFFF1E1BA);
    c.drawOval(Geo.elipse(Geo.kFachada), Paint()..color = corPiso);
    if (!ac) {
      final junta = Paint()
        ..color = const Color(0xFFE6D2A0)
        ..strokeWidth = 2;
      for (var g = 0.0; g < 360; g += 12) {
        c.drawLine(Geo.ponto(Geo.kAtrio + 0.02, g), Geo.ponto(Geo.kFachada - 0.02, g), junta);
      }
    }

    // Átrio central: jardim
    c.drawOval(Geo.elipse(Geo.kAtrio),
        Paint()..color = halloween ? const Color(0xFF120B1C) : (ac ? const Color(0xFF0A0A0A) : const Color(0xFFDDEFC8)));
    if (!ac) {
      final folha = Paint()..color = const Color(0xFFB9DC9C);
      for (var g = 20.0; g < 360; g += 40) {
        c.drawCircle(Geo.ponto(0.5, g), 16, folha);
      }
    }

    // Passarelas até o elevador panorâmico
    for (final g in Geo.passarelas) {
      final a = Geo.ponto(Geo.kElevador * 0.6, g);
      final b = Geo.ponto(Geo.kAtrio + 0.02, g);
      c.drawLine(a, b, Paint()
        ..color = corPiso
        ..strokeWidth = 44
        ..strokeCap = StrokeCap.butt);
    }
  }

  void _zona(Canvas c, Zona z) {
    final ehDestino = destino?.id == z.id;
    final ehElevadorDaRota = z.icone == 'elevator' && _temRota && (destino?.andar ?? 0) != 0;
    final apagada = calor == null && destino != null && !ehDestino && !ehElevadorDaRota;

    Color base = Color(z.cor);
    if (calor != null) {
      final maximo = max(1, calor!.values.fold(0, max));
      final n = calor![z.id] ?? 0;
      base = z.destino ? corCalor(n / maximo, escuro: ac) : (ac ? const Color(0xFF222222) : const Color(0xFFEDE6D6));
    } else if (ac) {
      base = ehDestino ? Cores.amareloAC : (ehElevadorDaRota ? Colors.white : const Color(0xFF333333));
    } else if (apagada) {
      base = Color.lerp(base, const Color(0xFFEDE6D6), 0.62)!;
    }

    final forma = z.ehSetor
        ? Geo.setor(Geo.kFachada + 0.02, Geo.kFundo, z.ang0! + 1, z.ang1! - 1)
        : (Path()..addOval(Rect.fromCircle(center: z.rect.center, radius: z.w / 2)));

    if (!apagada && !ac) {
      c.drawPath(forma.shift(const Offset(0, 4)),
          Paint()
            ..color = Colors.black.withValues(alpha: 0.14)
            ..maskFilter = const MaskFilter.blur(BlurStyle.normal, 5));
    }
    c.drawPath(forma, Paint()..color = base);
    c.drawPath(
        forma,
        Paint()
          ..style = PaintingStyle.stroke
          ..strokeWidth = ac ? 2 : 3
          ..strokeJoin = StrokeJoin.round
          ..color = ac ? Colors.white54 : Colors.white.withValues(alpha: 0.75));

    if (ehDestino) {
      final p = pulso.value;
      final brilho = ac ? Colors.white : Cores.laranjaRota;
      c.drawPath(
          forma,
          Paint()
            ..style = PaintingStyle.stroke
            ..strokeWidth = 7 + p * 14
            ..strokeJoin = StrokeJoin.round
            ..color = brilho.withValues(alpha: (1 - p) * 0.6));
      c.drawPath(
          forma,
          Paint()
            ..style = PaintingStyle.stroke
            ..strokeWidth = 6
            ..strokeJoin = StrokeJoin.round
            ..color = brilho);
    }

    final centro = z.centroRotulo;
    final corIcone = ac
        ? (ehDestino || ehElevadorDaRota ? Colors.black : Colors.white70)
        : Color.lerp(Color(z.cor), Colors.black, 0.35)!.withValues(alpha: apagada ? 0.45 : 1);
    final circulo = ac
        ? (ehDestino || ehElevadorDaRota ? Colors.white : Colors.black)
        : Colors.white.withValues(alpha: apagada ? 0.6 : 0.95);
    final raio = ehDestino ? 32.0 : 25.0;
    c.drawCircle(centro, raio, Paint()..color = circulo);
    _icone(c, iconeDe(z.icone), centro, raio * 1.25, corIcone);

    if (calor != null && z.destino) {
      _texto(c, '${calor![z.id] ?? 0}', centro + const Offset(0, 40),
          tamanho: 24, cor: ac ? Colors.white : const Color(0xFF3B1E00), peso: FontWeight.w900, larguraMax: 120);
    }
    if (z.icone == 'elevator' && (ehElevadorDaRota || destino == null) && calor == null) {
      _texto(c, 'Elevador', centro + const Offset(0, 58),
          tamanho: 22,
          cor: ac ? Colors.black : Colors.white,
          peso: FontWeight.w800,
          larguraMax: 160,
          fundo: ac ? Cores.amareloAC : const Color(0xFF546E7A));
    }
  }

  /// Nome do destino num balão fora do prédio, ligado à zona por uma linha.
  void _rotuloDestino(Canvas c, Zona z) {
    if (!z.ehSetor) return;
    final tp = _layout(z.nome, 28, FontWeight.w900, ac ? Cores.amareloAC : Colors.white, 260);
    final larg = tp.width + 30, alt = tp.height + 16;
    var pos = Geo.ponto(1.66, z.angMeio);
    pos = Offset(pos.dx.clamp(larg / 2 + 8, 700 - larg / 2 - 8), pos.dy.clamp(alt / 2 + 6, 994 - alt / 2));
    c.drawLine(z.centroRotulo, pos, Paint()
      ..color = ac ? Cores.amareloAC : const Color(0xE6202020)
      ..strokeWidth = 3);
    final r = RRect.fromRectAndRadius(Rect.fromCenter(center: pos, width: larg, height: alt), const Radius.circular(14));
    c.drawRRect(r, Paint()..color = ac ? Colors.black : const Color(0xF0202020));
    if (ac) {
      c.drawRRect(r, Paint()
        ..style = PaintingStyle.stroke
        ..strokeWidth = 3
        ..color = Cores.amareloAC);
    }
    tp.paint(c, pos - Offset(tp.width / 2, tp.height / 2));
  }

  void _rota(Canvas c) {
    final pts = caminho!;
    final path = Path()..moveTo(pts.first.dx, pts.first.dy);
    for (final p in pts.skip(1)) {
      path.lineTo(p.dx, p.dy);
    }
    Paint linha(Color cor, double largura) => Paint()
      ..color = cor
      ..style = PaintingStyle.stroke
      ..strokeWidth = largura
      ..strokeCap = StrokeCap.round
      ..strokeJoin = StrokeJoin.round;

    c.drawPath(path, linha(ac ? Colors.black : Colors.white, 26));
    c.drawPath(path, linha(_corRota.withValues(alpha: 0.25), 16));

    const traco = 26.0, ciclo = 46.0;
    final tracoPaint = linha(_corRota, 13);
    for (final metrica in path.computeMetrics()) {
      var inicio = -ciclo + tracejado.value * ciclo;
      while (inicio < metrica.length) {
        final s = max(0.0, inicio);
        final e = min(metrica.length, inicio + traco);
        if (e > s) c.drawPath(metrica.extractPath(s, e), tracoPaint);
        inicio += ciclo;
      }
      // Visitante andando pela rota, com seta apontando a frente
      final tg = metrica.getTangentForOffset(metrica.length * Curves.easeInOut.transform(caminhada.value));
      if (tg != null) {
        c.drawCircle(tg.position, 26, Paint()..color = _corRota.withValues(alpha: 0.28));
        c.drawCircle(tg.position, 17, Paint()..color = Colors.white);
        c.save();
        c.translate(tg.position.dx, tg.position.dy);
        c.rotate(-tg.angle);
        final seta = Path()
          ..moveTo(12, 0)
          ..lineTo(-8, -9)
          ..lineTo(-3, 0)
          ..lineTo(-8, 9)
          ..close();
        c.drawPath(seta, Paint()..color = _corRota);
        c.restore();
      }
    }
  }

  void _voceEstaAqui(Canvas c) {
    final pos = pontoTotem;
    final p = pulso.value;
    final cor = ac ? Colors.white : _azul;
    c.drawCircle(pos, 20 + p * 40, Paint()..color = cor.withValues(alpha: (1 - p) * 0.5));
    c.drawCircle(pos, 22, Paint()..color = ac ? Colors.black : Colors.white);
    c.drawCircle(pos, 15, Paint()..color = cor);
    _texto(c, 'VOCÊ ESTÁ AQUI', Geo.ponto(1.5, 90).translate(0, 14),
        tamanho: 26, cor: ac ? Colors.black : Colors.white, peso: FontWeight.w900, larguraMax: 400, fundo: cor);
  }

  void _saidaElevador(Canvas c, Offset pos) {
    final cor = ac ? Colors.white : _azul;
    c.drawCircle(pos, 20, Paint()..color = ac ? Colors.black : Colors.white);
    c.drawCircle(pos, 15, Paint()..color = cor);
  }

  void _pino(Canvas c, Offset ponta) {
    final sobe = sin(pulso.value * 2 * pi) * 6;
    final cor = ac ? Cores.amareloAC : const Color(0xFFD32F2F);
    c.drawOval(Rect.fromCenter(center: ponta, width: 30, height: 10), Paint()..color = Colors.black.withValues(alpha: 0.25));
    final topo = ponta.translate(0, -58 + sobe);
    final path = Path()
      ..moveTo(ponta.dx, ponta.dy + sobe * 0.2)
      ..quadraticBezierTo(topo.dx - 30, topo.dy + 22, topo.dx - 28, topo.dy)
      ..arcToPoint(Offset(topo.dx + 28, topo.dy), radius: const Radius.circular(28))
      ..quadraticBezierTo(topo.dx + 30, topo.dy + 22, ponta.dx, ponta.dy + sobe * 0.2)
      ..close();
    c.drawPath(path, Paint()..color = cor);
    c.drawPath(path, Paint()
      ..style = PaintingStyle.stroke
      ..strokeWidth = 4
      ..color = ac ? Colors.black : Colors.white);
    _icone(c, Icons.flag_rounded, topo, 28, ac ? Colors.black : Colors.white);
  }

  /// Rosa dos ventos fixa (Norte para cima do mapa).
  void _rosaDosVentos(Canvas c, Offset o) {
    final fundo = ac ? Colors.black : Colors.white.withValues(alpha: 0.92);
    final tinta = ac ? Colors.white : const Color(0xFF263238);
    final norte = ac ? Cores.amareloAC : const Color(0xFFD32F2F);
    c.drawCircle(o, 50, Paint()..color = fundo);
    c.drawCircle(o, 50, Paint()
      ..style = PaintingStyle.stroke
      ..strokeWidth = 2.5
      ..color = tinta.withValues(alpha: 0.6));
    for (var i = 0; i < 4; i++) {
      final a = i * pi / 2;
      final ponta = o + Offset(sin(a), -cos(a)) * 34;
      final l1 = o + Offset(sin(a + pi / 2), -cos(a + pi / 2)) * 7;
      final l2 = o + Offset(sin(a - pi / 2), -cos(a - pi / 2)) * 7;
      c.drawPath(Path()
        ..moveTo(ponta.dx, ponta.dy)
        ..lineTo(l1.dx, l1.dy)
        ..lineTo(l2.dx, l2.dy)
        ..close(), Paint()..color = i == 0 ? norte : tinta.withValues(alpha: 0.75));
    }
    const letras = ['N', 'L', 'S', 'O'];
    for (var i = 0; i < 4; i++) {
      final a = i * pi / 2;
      _texto(c, letras[i], o + Offset(sin(a), -cos(a)) * 43,
          tamanho: 15, cor: i == 0 ? norte : tinta, peso: FontWeight.w900, larguraMax: 30);
    }
  }

  TextPainter _layout(String t, double tamanho, FontWeight peso, Color cor, double larguraMax) => TextPainter(
        text: TextSpan(text: t, style: TextStyle(fontSize: tamanho, color: cor, fontWeight: peso, height: 1.1)),
        textAlign: TextAlign.center,
        textDirection: TextDirection.ltr,
        maxLines: 3,
      )..layout(maxWidth: larguraMax);

  void _icone(Canvas c, IconData i, Offset centro, double tamanho, Color cor) {
    final tp = TextPainter(
      text: TextSpan(
        text: String.fromCharCode(i.codePoint),
        style: TextStyle(fontSize: tamanho, fontFamily: i.fontFamily, package: i.fontPackage, color: cor),
      ),
      textDirection: TextDirection.ltr,
    )..layout();
    tp.paint(c, centro - Offset(tp.width / 2, tp.height / 2));
  }

  void _texto(Canvas c, String t, Offset centro,
      {double tamanho = 24, Color cor = Colors.white, FontWeight peso = FontWeight.w700, double larguraMax = 300, Color? fundo}) {
    final tp = _layout(t, tamanho, peso, cor, larguraMax);
    if (fundo != null) {
      c.drawRRect(
          RRect.fromRectAndRadius(
              Rect.fromCenter(center: centro, width: tp.width + 28, height: tp.height + 14), const Radius.circular(14)),
          Paint()..color = fundo);

class _PisoTatilPainter extends CustomPainter {
  @override
  void paint(Canvas canvas, Size size) {
    final r = RRect.fromRectAndRadius(
      Offset.zero & size,
      const Radius.circular(6),
    );
    canvas.drawRRect(r, Paint()..color = const Color(0xFFF7D24A));
    final ponto = Paint()..color = const Color(0xFFDDA800);
    for (var y = 8.0; y < size.height; y += 12) {
      for (var x = 8.0; x < size.width; x += 14) {
        canvas.drawCircle(Offset(x + ((y ~/ 12).isOdd ? 7 : 0), y), 3.2, ponto);
      }
    }

// Servidor estático para o build web, acessível pela rede local (para o QR Code do totem).
// Uso: node ferramentas/servidor.js [porta]
const http = require('http');
const fs = require('fs');
const path = require('path');

const RAIZ = path.join(__dirname, '..', 'build', 'web');
const PORTA = Number(process.argv[2] || 8090);
const TIPOS = {
  '.html': 'text/html; charset=utf-8', '.js': 'application/javascript', '.mjs': 'application/javascript',
  '.wasm': 'application/wasm', '.json': 'application/json', '.png': 'image/png', '.webp': 'image/webp',
  '.otf': 'font/otf', '.ttf': 'font/ttf', '.frag': 'application/octet-stream', '.bin': 'application/octet-stream',
};

http.createServer((req, res) => {
  let p = decodeURIComponent(req.url.split('?')[0]);
  if (p.endsWith('/')) p += 'index.html';
  const arquivo = path.normalize(path.join(RAIZ, p));
  if (!arquivo.startsWith(RAIZ)) { res.writeHead(403); return res.end(); }
  fs.readFile(arquivo, (err, dados) => {
    if (err) { res.writeHead(404); return res.end(); }
    res.writeHead(200, { 'Content-Type': TIPOS[path.extname(arquivo)] || 'application/octet-stream', 'Cache-Control': 'no-cache' });
    res.end(dados);
  });
}).listen(PORTA, '0.0.0.0', () => console.log(`Servindo ${RAIZ} em http://0.0.0.0:${PORTA}`));

function blocoQR(texto, sub) {
  return `<div class="qr"><canvas width="21" height="21" data-seed="${texto}"></canvas><div><b>${texto}</b><span>${sub}</span></div></div>`;

function desenharQR() {
  ui.querySelectorAll('canvas').forEach(cv => {
    const c = cv.getContext('2d'); let s = 0;
    for (const ch of cv.dataset.seed) s = (s * 31 + ch.charCodeAt(0)) >>> 0;
    const rnd = () => (s = (s * 1664525 + 1013904223) >>> 0) / 4294967296;
    c.fillStyle = '#fff'; c.fillRect(0, 0, 21, 21); c.fillStyle = '#17382A';
    for (let y = 0; y < 21; y++) for (let x = 0; x < 21; x++) if (rnd() > .52) c.fillRect(x, y, 1, 1);
    for (const [ox, oy] of [[0, 0], [14, 0], [0, 14]]) {
      c.fillStyle = '#fff'; c.fillRect(ox, oy, 7, 7);
      c.fillStyle = '#17382A'; c.fillRect(ox, oy, 7, 7);
      c.fillStyle = '#fff'; c.fillRect(ox + 1, oy + 1, 5, 5);

    }
  });
}
